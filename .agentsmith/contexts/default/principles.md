# Test Website principles

This repository is a disposable static website for Agent Taro tests.

- Keep changes small, visible, and limited to the requested ticket.
- Preserve the dependency-free HTML, CSS, and Python test setup.
- Add or update a regression test when behavior can be checked automatically.
- Do not add credentials, customer data, private screenshots, or production integrations.
- Do not deploy or merge automatically. Leave the pull request for human review.
