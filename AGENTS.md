# Test Website instructions

This is a disposable fixture for evaluating ticket-to-code agents.

- Keep the site dependency-free unless a ticket explicitly requires otherwise.
- Preserve semantic HTML and responsive behavior.
- Add or update tests for every behavior change.
- Run `python3 -m unittest discover -s tests -v` before completing work.
- Do not add secrets, private data, analytics, network calls, or deployment configuration.
- Do not merge or deploy automatically.
